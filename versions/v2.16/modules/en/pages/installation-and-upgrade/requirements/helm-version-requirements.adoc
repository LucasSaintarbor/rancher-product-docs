This section contains the requirements for Helm, which is the tool used to install Rancher on a high-availability Kubernetes cluster.

[#_identifying_the_proper_helm_version]
== Identifying the Proper Helm Version

Select any Helm v3 or v4 version compatible with your Kubernetes version range from the https://www.suse.com/suse-rancher/support-matrix/all-supported-versions[Rancher Support Matrix].

Helm v3 or v4 is backward compatible with three previous minor versions of Kubernetes (n-3). It does not guarantee forward compatibility with newer Kubernetes versions.

To apply this rule, you may need to reference the following two external resources:

* *Helm Version Compatibility:* Refer to the https://helm.sh/docs/topics/version_skew/[Helm Version Support Policy] and select the version matching the rule for your Rancher target version.
* *Rancher’s Kubernetes Support Range:* Use the https://www.suse.com/suse-rancher/support-matrix/all-supported-versions[Rancher Support Matrix] to identify the Kubernetes versions supported by your target Rancher version.

[#_example]
=== Example

* *Scenario:* You are targeting Rancher v2.15.1, which supports Kubernetes versions 1.34 through 1.36.
* *Application:* Our rule requires a Helm version that supports this entire range. Helm does not provide forward compatibility. You must verify compatibility with the highest version, Kubernetes v1.36.
* *Result:* You find that Helm v4.2.x and v4.3.x support the Kubernetes v1.34 through v1.36 range.
* Although multiple versions work, we recommend Helm v4.3.x because it is the newest Helm version supporting the Kubernetes range.

[#_additional_notes]
== Additional Notes

* When using tools that run Helm commands for you (like Terraform), you must make sure they are configured to use the correct Helm version.
