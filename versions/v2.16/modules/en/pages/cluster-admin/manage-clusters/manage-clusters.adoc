[#_configuring_tools]
== Configuring Tools

{rancher-product-name} contains a variety of tools that aren't included in Kubernetes to assist in your DevOps operations. {rancher-product-name} can integrate with external services to help your clusters run more efficiently. Tools are divided into the following categories:

* Alerts
* Notifiers
* Logging
* Monitoring
* Istio Service Mesh

Tools can be installed through *Apps.*
