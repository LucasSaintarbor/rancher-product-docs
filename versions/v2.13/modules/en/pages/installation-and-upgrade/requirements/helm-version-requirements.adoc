This section contains the requirements for Helm, which is the tool used to install Rancher on a high-availability Kubernetes cluster.

[#_identifying_the_proper_helm_version]
== Identifying the Proper Helm Version

Select a Helm version compatible with your Kubernetes version range from the https://www.suse.com/suse-rancher/support-matrix/all-supported-versions[Rancher Support Matrix].

Helm is backward compatible with three previous minor versions of Kubernetes (n-3). It does not guarantee forward compatibility with newer Kubernetes versions.

To apply this rule, you may need to reference the following two external resources:

* *Helm Version Compatibility:* Refer to the https://helm.sh/docs/topics/version_skew/[Helm Version Support Policy] and select the version matching the rule for your Rancher target version.
* *Rancher’s Kubernetes Support Range:* Use the https://www.suse.com/suse-rancher/support-matrix/all-supported-versions[Rancher Support Matrix] to identify the Kubernetes versions supported by your target Rancher version.

[#_applying_compatibility_rules]
=== Applying Compatibility Rules

* *Scenario:* You are targeting a specific Rancher version that supports a range of Kubernetes versions.
* *Application:* You need a Helm version that supports this entire Kubernetes range. Helm does not provide forward compatibility. You must verify compatibility with the highest supported Kubernetes version.
* *Result:* You find multiple Helm versions that support your target Kubernetes range.
* When multiple versions work, use the newest Helm version that supports the Kubernetes range.

[#_additional_notes]
=== Additional Notes

* When using tools that run Helm commands for you (like Terraform), you must make sure they are configured to use the correct Helm version.
