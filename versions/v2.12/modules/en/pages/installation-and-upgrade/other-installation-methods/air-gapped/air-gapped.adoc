This section is about using the Helm CLI to install the Rancher server in an air gapped environment. An air gapped environment could be where Rancher server will be installed offline, behind a firewall, or behind a proxy.

For more information on each installation option, refer to {xref-install-upgrade}[this page.]

Throughout the installation instructions, there will be _tabs_ for each installation option.

== Installation Outline

. {xref-air-gap-private-reg}[Set up infrastructure and private registry]
. {xref-air-gap-publish-images}[Collect and publish images to your private registry]
. {xref-air-gap-install-k8s}[Set up a Kubernetes cluster]
. {xref-air-gap-rancher-ha}[Install Rancher]

== Upgrades

To upgrade Rancher with Helm CLI in an air gap environment, follow {xref-rancher-upgrades}[this procedure.]
